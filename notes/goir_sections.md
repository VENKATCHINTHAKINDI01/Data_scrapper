# GOIR sections to use for hand searches (2026 orders, gaps) — from the GOIR search form, 16 Oct 2026

The automatic run (tools/run_batches.sh) does NOT need sections: the topic filter keeps rule orders from any section.
Use this list when searching goir.ap.gov.in by hand: set DEPARTMENT, then one of the "Use" sections, G.O TYPE = Ms.
"Check" = meaning of the section code not confirmed; open 1–2 orders before relying on it.
